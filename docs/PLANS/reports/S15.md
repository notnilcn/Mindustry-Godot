## Deviations from the plan

- **Helper placement by topic** (RULES §8: line ranges are a guide):
  - `io_bench_stat` (BASE 3411–3422, the package's bench range) → `exec/io.rs`, its only caller
    `cmd_io_bench_save`; `percentile` (3405–3409) stays in `exec/bench.rs` (used by `cmd_bench`
    and `cmd_bench_sim_core`) and `exec/io.rs` imports `super::bench::percentile`.
  - `struct BareBuildingHooks` + `impl WorldHooks` (BASE 3697–3722, content range) →
    `exec/world.rs`, its only user `cmd_world_multiblock`.
  - `preview_image_checksum` (BASE 4410–4417, editor range) → `exec/maps.rs` (four maps callers vs
    two in editor); `exec/editor.rs` imports `super::maps::preview_image_checksum`.
  - `write_dump`/`read_golden_checksums` stay in `exec/scenario.rs` (used by `cmd_run` and by
    `cmd_sim`/`cmd_replay`), imported by `exec/bench.rs`.
  - `boot_content`/`boot_content_with` stay in `exec/content.rs` (topic); the five sibling files
    that boot content (`assets`, `io`, `world`, `editor`, `maps`) import
    `super::content::boot_content`.
  - Consequently `exec/mod.rs` needs `use bench::cmd_sim_core_reset_play_cycle;` and
    `use scenario::{cmd_run, load_scenario_catalog};` for the helpers that stayed behind.
- **`cli` files**: one file per enum exactly as the package table, no combined `small.rs`.
- **`server/commands/tests.rs`**: the inline `mod tests { … }` body is dedented by one level; its
  `use super::*;` becomes `use super::chat::*; use super::console::*;` (RULES §3.3 "moved tests see
  less"). Module depth is unchanged, so `super::super::config` inside the tests still resolves.
- **Path rewrites (the 7 `move_check` only-in-old lines)**: `super::config::ServerConfig` →
  `crate::server::config::ServerConfig` (2×), `super::TICKS_PER_SECOND` → `crate::server::…` (3×),
  `super::autosave::{spacing_ticks,rotation_order}` → `crate::server::autosave::…` (2×). The old
  relative paths meant `crate::server`, which is one level up from the new `commands::{console,chat}`.
- Two imports the compiler had to add: `exec/io.rs` needs `super::bench::percentile`;
  `server/commands/chat.rs` needs `crate::server::host::Admins` in scope for `state.net.kick`.
