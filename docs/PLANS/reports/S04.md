## Deviations from the plan

1. **`strip_color_tags` no longer exists at the branch point.** The plan's `util.rs` list names it
   (`batch_c.rs:351` at `291e30a8`), but commit `1f104114` (already on `main` before S04 branched)
   deleted it, which is why `batch_c.rs` is 4006 lines, not the plan's 4042. It was not moved and has
   no moves-table row; nothing else named in either destination table is missing.
2. **Line numbers.** Section boundaries were located with the `// ----` comments and the branch-point
   file (all ranges above). The plan's ranges are at `291e30a8` and are 36 lines lower after the
   `strip_color_tags` deletion. `moves/S04.tsv` follows RULES §7 and carries the **`291e30a8`**
   (`BASE`) line numbers; subtract 36 for `batch_c.rs` lines ≥ 385 to compare with the branch point.
3. **Tests for Part A live inline in `campaign/planet/mod.rs`** (the plan allows `launch.rs` or
   `mod.rs`). The test bodies are unchanged; two `#[cfg(test)] use self::…` imports were added so the
   inline `mod tests` still resolves `planet_launch_clears_loadout` and the `SECTOR_*`/link helpers.
4. **Section-comment placement.** The `// ---- Scene access ----` header (old `planet.rs` 623–625)
   starts `planet/scene.rs`, and `// ---- Sector markers ----` (1381–1383) starts
   `planet/overlays.rs`, instead of trailing the previous file as the raw line ranges imply. Comments
   are skipped by `move_check`; no code line moved for this.
5. **`#[allow(unused_imports)]` on the `SunMesher`/`sun_mesh_data` re-export.** `ui` is a private
   module and no in-crate path names either item (grep), so a plain `pub use` trips `unused_imports`
   under `-D warnings`. The attribute is only there to keep the old
   `crate::ui::planet::{SunMesher, sun_mesh_data}` paths resolving for C01.
6. **`sector_panel.rs` was not split further.** It is 1128 lines but has no internal section comment
   (only the one at its head), and the plan's split condition was "if a clear section comment splits
   it". It is under the 1500-line ceiling.
7. **Moves table shape.** `moves/S04.tsv` has 284 rows: every top-level fn/const/struct plus every
   `impl` method (`item_name` is the bare method name so C01 can grep it in the new file), the
   `mod tests` module, and the `dispatch` move. The container `impl` blocks themselves are omitted:
   `impl MindPlanetView` is split across three files, so a single row would mis-map a line inside it;
   its methods are listed individually.
8. **The `git mv ui/planet.rs ui/planet/mod.rs` rename (100 %) landed in the first S04 commit**
   (`7f4f3168`) because `git mv` stages immediately; its content split landed in `7be7dce9`. History
   still follows the file (`R100`), only the commit message of the first one does not mention it.
9. No signature, behaviour, `#[func]`, signal, id or meta-key string changed; no `.tscn`, manifest,
   binding, golden or scenario was touched, and `dialogs/campaign/mod.rs` was not edited.
