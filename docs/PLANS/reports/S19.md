## Deviations from the plan

1. **`editor/api_state.rs` was not created.** The package's `mod.rs` row says "keep a small primary
   block with any `#[signal]`s, and with the state funcs at 284–503 if there are no signals".
   `MindEditor` has no `#[signal]`, so the state funcs stay in `mod.rs`'s primary
   `#[godot_api] impl MindEditor`, and the `api_state.rs` row of the table does not apply. All other
   `api_*.rs` files are exactly the table's sections.
2. **`api_data` has no section comments to split at.** Lines 879–2221 contain only doc comments, so
   the five files were cut at item boundaries by topic, using the doc-comment start of each first
   item (filters+sector generate: 881–1114; objectives+markers: 1116–1250;
   waves/locales/units/spawns/wave-graph: 1252–1465; processors+logic: 1467–1681; data
   patches/content/assets/export/save: 1683–2221). The doc lines above each `fn` move with it, so
   the plan's `fn`-line ranges shift by 1–6 lines.
3. **`locales_json`/`set_locales_json` live in `api_waves.rs`.** They are the `MapLocalesDialog`
   data and sit between the wave functions in source order; keeping them there preserved item order
   and made the five cuts contiguous, rather than inventing a sixth `api_locales.rs`.
4. **`net/probe.rs` also carries `open_online` and `push_identity`** — the package puts the "1376–1449
   head of the private impl" in `probe.rs`; it holds the connector bring-up (which the probes call),
   so the pairing is kept literally.
5. **Visibility only as the compiler requires, and exactly at the original scope.** Every method and
   free fn that was private in `net`/`editor`/`ui::root` and left its `mod.rs` became `pub(super)`
   (the old module, no wider). Two `net::adapters` structs (`SimHostContent`, `MemberOrigin`) and
   their fields also became `pub(super)` because `net::drain` constructs them. `pub(crate)` items
   (`root/accessors.rs`'s four accessors, `editor_views`'s `valid_place_rect`) keep their exact
   visibility.
6. **Sibling-module imports.** `use super::*;` gives a child the parent's items but not a *sibling
   module's* contents, so `root::{boot,prompts}`, `net::{actions,drain,probe,roster}`, `net/mod.rs`
   and `editor::{api_objectives,api_palette}` carry one extra explicit `use super::free::…` /
   `use super::adapters::…` / `use self::adapters::…` line. `net/tests.rs` imports the moved free
   helpers from `super::adapters` (the old `use super::{…}` list split in two).
7. **`ui/editor_views/mod.rs` re-exports three classes with `#[allow(unused_imports)]`.**
   `mind-gdext` is a `cdylib` and `lib.rs` declares `mod ui;` privately, so a `pub use` for a class
   with no in-crate path user warns. Only `MindMapEditorDialog` is named by Rust
   (`ui/root`, `audio/mod.rs`); the other three are instantiated by their `.tscn` scenes through
   `#[derive(GodotClass)]`, and the re-exports exist so the old module paths and the module-doc
   links still resolve.
8. File sizes: the 300–1000 target is met everywhere except `net/mod.rs` (1388; it must keep the
   primary block — the class has signals — and the struct/`INode` impl) and
   `editor_views/map_editor_dialog.rs` (1023). Both are below the 1500 non-test ceiling.
9. No `Cargo.toml`, `Cargo.lock`, `.tscn`, manifest, golden, scenario or binding file was touched.
