## Deviations from the plan

1. **Line ranges matched.** The plan's ranges are at `291e30a8`; this branch
   starts at `1dfed5ab`. `git diff 291e30a8 1dfed5ab -- batch_f.rs batch_i.rs` is
   empty, so every range in the package applied unchanged; nothing was missing
   and nothing extra existed.
2. **`auto_fixed_drops_trailing_zeros`** went to `editor/map_assets/helpers.rs`
   per the package's test table, although `auto_fixed` itself is defined in the
   schematic-info section. `schematic_info::auto_fixed` is therefore
   `pub(in crate::ui::dialogs)` (the only cross-module use is that test); see
   Follow-ups for the C01 cleanup.
3. **`engine_available`** moved to `editor/util_f.rs` per the package; its
   `mod tests` is `pub(crate)` and the helper is `pub(crate)`, so the three other
   test modules import it with one `use` line. No assertion or test body changed.
4. **`custom_rules` split into 5 children** (the package allows 3–5): `rows`,
   `categories`, `team_rules`, `planet_env`, `overlays`, named after the section
   comments. `NumberSpec` + its `impl` stayed in `mod.rs` because its builder
   methods are called from both `categories.rs` (`setupMain`) and `rows.rs`;
   `impl Default for CustomRulesState` and the `DialogController` impl also stay.
5. **Imports of the two new directories.** Children carry only `use super::*;`:
   a child glob imports the parent's private items *and* its `use` bindings
   (Rust privacy: `mod.rs` and its descendants), so every child sees the
   parent's Godot imports and the parent's `rules::util::*` glob. This avoided
   duplicating ~20 import lines across 11 children. `mod.rs` uses
   `use self::<child>::*;` for the items it calls.
6. **`editor_maps` / `canvas_edit` imports.** The shared `batch_campaign2` items
   are imported by their old full path (`crate::ui::dialogs::batch_campaign2::{…}`)
   exactly as W1-DIALOGS-COMMON requires, so the S03 shim keeps them valid:
   `{MapListState, install_frame_tick, maplist_add_pane_button, maplist_build,
   maplist_load_settings, maplist_maps, maplist_rebuild, maplist_refresh_registry}`
   for `editor_maps` and `{Deferred, install_frame_tick}` for `canvas_edit`.
7. **Shim `dispatch` visibility** is `pub(super)` (RULES §3 / COMMON) rather than
   the old `pub fn`; `dialogs/mod.rs` (parent) and its test still call it.
8. **Stub doc lines.** The F2 staging sentence "Filled by S09 (docs/PLANS)." was
   removed from the filled leaves' `//!` docs; the sentence and the
   `//! Upstream:` line were kept. New child files use the RULES §3.7 header.
9. **`use godot::classes::box_container::AlignmentMode`** was dropped from
   `editor/util_f.rs` (the moved `square_cell` calls the fully qualified path;
   the import was only needed by `map_processors`, which keeps it).
