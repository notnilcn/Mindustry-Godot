## Deviations from the plan

1. **Move-table line numbers are at `1dfed5ab`, not the plans' `291e30a8`.** `batch_a.rs` (23
   changed lines) and `simple.rs` (6) differ between the two — the `open_content_info(content)`
   fix also dropped the dialog parameter from `database_entry_button`/`content_icon_cell` — so the
   plan's absolute lines are stale. All new-file lines are at 1dfed5ab (this branch's merge base),
   which is what C01 needs to rewrite references into the merged tree.
2. **The stale `// @@PART7@@` marker was dropped.** `batch_a.rs:3958` (at 1dfed5ab) carries a
   `// @@PART7@@` marker from the earlier manual split in commit `2c076077`; nothing in the repo
   consumes it (grepped). It is not an item, so it was not carried into a leaf.
3. **`menu/util.rs` was added** (the package allows it when `simple.rs` has a helper shared by more
   than one menu dialog): `rich` is used by about, credits and full_text. `menu/mod.rs` gained one
   `pub mod util;` line.
4. **`batch_a.rs` was drained over two commits** (`settings/` first, `database/` second, with a
   temporary `batch_a` that still held the other three controllers) so every commit compiles and
   bisects; `simple.rs` → `menu/` is the third code commit. Each commit keeps
   `every_manifest_id_resolves_exactly_once` green because ids move with their arms.
5. **`open_content_info` visibility.** The package says "keep it `pub` in `settings/util.rs`", so it
   is `pub` (it was `pub(super)`); the shim's `pub use` re-export requires that. This is wider than
   `dialogs`, deliberately, per the package (RULES §3.2's "never go to `pub`" is overridden here by
   the package's explicit instruction).
6. **Shim `dispatch` is `pub(super)`**, per RULES §3's shim template; the original batch files had
   `pub fn dispatch`. The only callers are `dialogs/mod.rs` (its `controller_for` chain and the
   test) — both inside `dialogs`, so nothing outside lost access.
7. **F2's stub `//!` lines were replaced.** Each filled leaf's "Filled by S06 (docs/PLANS)" sentence
   became the real one-sentence description and its `Upstream:` line was expanded to
   `core/src/mindustry/ui/dialogs/<X>.java` (RULES §3.7's form).
8. The package's line ranges are 1–2 lines off at 1dfed5ab (e.g. `pick_file` ends 1295, not 1296;
   `open_content_info` is 277–292). No item was missing or extra, and all ten ids were checked
