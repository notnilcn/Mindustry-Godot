## Deviations from the plan

1. **No util-leaf merge for H05a** — the package's step 4 names only H05b and
   H05c; `settings/util.rs` is already the single shared leaf for
   settings+database and it stays the home of `open_content_info`.
2. **`dialogs::common::defer` has no consumer in this sub-package.** A grep for
   `defer_action`, `Deferred`, `install_frame_tick` over `settings/**`,
   `database/**`, `menu/**`, `dev/**` finds no local copy (the only deferred
   seam is `Callable::call_deferred` in `language.rs`, which has no shared
   equivalent). Nothing to delete or adopt.
3. **`factory::on_pressed` / `on_text_changed` were not adopted.** The package
   marks them "optional and large", and most pressed closures here capture
   more than the plain shape (`args` used, or a `bind_mut` block); the
   `text_changed` sites ignore the emitted text and re-read the field, which
   `on_text_changed`'s `String` action does not model. Recorded as a
   follow-up rather than forced.
4. **`factory::scroll()` was not adopted.** Every `MindScroll::new_alloc()` site
   here (3) calls `set_scrolling_disabled` and adds its own child *before* any
   `content()`; `factory::scroll()` would create and attach an extra `Content`
   table — a behaviour change, so the sites stay raw.
5. **`menu/util.rs` stays as a one-line re-export** instead of deleting the
   file: `menu/mod.rs` is a group module (owned by the orchestrator/C01, not by
   a W2 leaf), so the path the three menu dialogs import is preserved and only
   the duplicate body is gone.
6. **`json_object` was deleted as dead code** (`#[allow(dead_code)]`, zero
   callers). Its body equals `gdutil::variant::parse_object_from_gstring`
   (F1 catalogue row 65), so if C01 resurrects it, adopt that helper.
7. **Observability drift in `database_dialog.rs`:** the `dict_bool_try_or`
   call sites now pass an explicit `false` default, which is the same value the
   deleted 2-arg wrapper produced (`as_bool(..).unwrap_or(false)`).
