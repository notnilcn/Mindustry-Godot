## Deviations from the plan

1. **The base is `1dfed5ab`, not `291e30a8`.** The plan's line numbers are stale
   by one or two lines for `batch_d` and by ~2566 lines for `batch_e`: `main`
   gained `4c671d61 "fix(ui): port MapLocalesDialog [findings #6]"` after the plan
   base, replacing the 11-line `// __APPEND__` stub with a real ~2305-line
   dialog. The move table therefore uses `1dfed5ab` line numbers (the branch
   point, which RULES §6 also uses for `move_check`).
2. **`map_locales` became a directory.** The package says "Move it verbatim,
   marker included" because it assumed a stub; there is no marker and no stub at
   the base. The real file is ~2305 lines, so per COMMON ("Do this when a leaf
   would exceed about 1500 lines") it became `map_locales/{mod,model,ui}.rs`:
   `model.rs` = constants + pure status/column/key/bundle helpers (5510–5941)
   plus the tests that exercise them, `mod.rs` = struct + `DialogController` +
   the build-method impl (6284–6763), `ui.rs` = widget/sub-dialog/card builders
   (5942–6283, 6764–7814).
3. **`map_objectives` split by topic, not by section comments.** The old range
   has no `// --` markers (only the outer `// ---` banner), so the split follows
   the example names: `mod.rs` = constants/struct/hooks, `list.rs` = objective
   list, panel, overlays and picker wiring (3903–4551), `edit.rs` = the
   `ObjectiveValue` interpreters, field rows and verts/seq/marker editors
   (4552–5509) plus the verts/`editor_pos` tests. `objective_field_row` moved
   with the interpreters (its callees) and `hex_byte` stayed in `list.rs`
   (`pub(super)`, imported by `edit.rs`).
4. **`strip_colors` / its test no longer exist.** Commit `1f104114` replaced the
   local copy with `mind_core::util::strip_colors`; the plan's "`strip_colors` →
   `util_d.rs`" test row is stale. The only `batch_d` tests are the three path
   helpers, and they moved to `pickers/file_chooser.rs` as the plan says (their
   functions live in `util_d.rs` and come in through the util glob).
5. **Cross-leaf helpers stayed in their defining leaf** (see Visibility) rather
   than moving into `util_d`/`util_e`, so every row of the package's line table
   keeps its destination. RULES §3.2's "scattered users" rule was satisfied by
   widening their visibility to the nearest common ancestor (`pub(super)`).
6. **`util_e::Overlay` members widened** (fields `layer`/`frame_box`, method
   `add_content`): `map_generate` and `map_locales` read them, and a moved
   struct's read fields take the same visibility as the struct (RULES §3.2).
7. **`ensure_locale` import moved into the `map_locales` test module.** At file
   scope rustc reports it unused (only the moved tests call it), which would fail
   `-D warnings`; the import move is the §3.3 import edit.
8. **Shim `dispatch` narrowed `pub` → `pub(super)`** exactly as RULES §3
   prescribes; `dialogs/mod.rs` is the only caller and is the parent module.
9. **`move_check` `only-in-old` = 7**, all explained in Verification.
