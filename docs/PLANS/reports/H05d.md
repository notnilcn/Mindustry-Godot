## Deviations from the plan

1. **No util-leaf merge for H05d** — step 4 of the package names only H05b and
   H05c; each of `rules/`, `logic/editor/` and `mods/` already has exactly one
   `util.rs` (plus `logic/editor/signals.rs`), and those stay. The only
   cross-group dedupe is `mods/util.rs` re-exporting `rules/util.rs`'s
   `dialog_node`/`fmt_key` (identical bodies, both files inside H05d's
   directories).
2. **Re-exports, not renamed call sites.** The package's own exception is
   `editor/editor_maps.rs` (H05c) importing `rules/util.rs` helpers by name;
   `rules/util.rs` is also glob-imported by `rules/custom_rules/mod.rs`. So the
   deleted `variant_*`, `rich`, `ui_call`, `defer_action` become re-exports
   under their old names instead of rewriting every call site. Same for the
   `dict_*` names in `logic/editor/util.rs` and the `variant_*` names in
   `mods/util.rs`. C01 can trim the re-exports once it repoints `editor_maps.rs`
   (see Follow-ups).
3. **`mods/util.rs::dict_bool`/`dict_i64` kept local** — see the table note
   above: F1's catalogue row 2 maps the *lenient* `dict_bool`, but batch_g's
   composition is the narrower `to_bool_int_only`/`to_i64_number`. Adopting
   `dict_bool_or`/`dict_i64_or` would silently accept `"true"`/`"1"`/bools
   where the old code returned the default.
4. **`factory::on_pressed` / `factory::on_text_changed` were not adopted.**
   The package marks them "optional and large". Every site here builds a named
   `Callable::from_fn` first (there is no inline
   `connect("pressed", &Callable::from_fn(…))` shape), several use the emitted
   `args`, and rewriting them would move load-bearing signal handling for no
   semantic gain. Same decision as H05a.
5. **`factory::scroll()` was not adopted.** The single `MindScroll::new_alloc()`
   site (`mods_dialog.rs`) adds a child table and calls
   `set_scrolling_disabled` before any `content()`; the factory would create and
   attach an extra `Content` table (a behaviour change).
6. **`add_close_button(210.0)` kept at `mods_dialog.rs:233`** — its return value
   is mutated (`set_custom_minimum_size`), and `add_default_close_button()`
   returns `()`. The three ignored-return sites adopt the default helper.
7. **The nine raw `Label::new_alloc()` sites in `logic/editor/` were kept.**
   The package says to switch to the kit label factory "only where the factory
   sets nothing extra"; every one of them sets a `Label`-only property
   (`set_vertical_alignment`, `set_horizontal_alignment`, font/outline
   overrides, `set_autowrap_mode`, minimum sizes) and is stored/reused as
   `Gd<Label>`. `factory::label` builds a `MindLabel` (`RichTextLabel`), so the
   swap would change the widget class and the rendered text handling, not just
   the constructor.
8. **`logic/canvas_edit.rs` is unchanged.** It consumes `rules::util::*`
   (`dict_i64`, `rgba8_color`) which are still there, and it imports
   `Deferred`/`install_frame_tick` from the `batch_campaign2` shim rather than a
   local copy; repointing that import at `common::defer` belongs to C01 when the
   shim is deleted (not a W2 copy).
9. **`rules/util.rs::variant_i64` body is not byte-identical** to
   `to_i64_typed` (the `STRING_NAME` conversion path above), but the fallback
   order is unchanged for every value JSON can produce and F1's catalogue names
   the adoption. Recorded rather than keeping a copy that would preserve a
   latent panic.
