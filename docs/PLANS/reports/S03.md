## Deviations from the plan

1. **Line drift.** The worktree starts at `1dfed5ab`, not the plans' `291e30a8`. All destination
   boundaries were taken from the section comments at HEAD (e.g. the shared-helper block is
   72–673, not 71–723; `ResearchDialog` starts at 674). No item was missing or extra: the item
   audit (definitions in old vs new) and the string-literal audit are clean. `moves/S03.tsv`
   uses `291e30a8` line numbers, as RULES §7 requires.
2. **One commit carries two groups: `schematics/*` and `launch_loadout.rs`.** `launch_loadout`
   reads `SCHEMATIC_COLUMN_WIDTH`, so the id cannot compile with the const moved but
   launch-loadout left behind; moving both in one commit keeps every commit green. The
   `loadout`/`sector_stats` commit follows separately.
3. **Test placement.** The package's table sends the markup/strip helpers to `campaign/util.rs` and
   the other schematic tests to `files.rs`. `schematics_strip_symbols`, `schematics_tag_plain` and
   `schematics_tag_color` are code of `schematics_dialog.rs` (bc2 1605–2584 range) and are used
   only inside `schematics/`, so their tests sit at the end of `schematics_dialog.rs` rather than
   widening those helpers to `pub(in crate::ui::dialogs)` for a util test (RULES §3.2 "never a
   wider scope than needed"). The generic `color_tags_strip` test does go to `util.rs` as tabled.
4. **`strip_color_tags` does not exist at HEAD.** The plan lists it at bc2 441; the helper section
   has no such fn (it uses `mind_core::util::strip_colors`). Nothing was dropped.
5. **The shim drops the stale `// Source:` header block.** It named seven Java dialogs no longer in
   the file; the shim keeps the two mandatory header lines and the `//! Moved to …` doc.
6. **`common/` not adopted.** `campaign/util.rs` keeps its local `ui_call`, `rich`, `Deferred` and
   `install_frame_tick` copies (F1 added exact duplicates in `common/`); W1 is a move, so adoption
   is left to W2/H04 as the plan intends.
7. **Leaf headers** are the F2 stubs (SPDX + `Ported from` + one-line doc + `Upstream:`), so the
   three `sector.rs` leaves now carry the citations 02-FINDINGS #12 asked for.
