## Deviations from the plan

1. **One atomic code commit.** Deleting the local helpers and switching their call sites must land
   together (a split commit would not compile), and the planet re-exports depend on the campaign
   shared set, so `d5b99303` carries the whole adoption. The report is the second commit.
2. **`defer_action` does not exist at HEAD.** The plan lists it as duplicated and to be replaced
   with `common::defer`; S03 moved only `Deferred`/`install_frame_tick`, so there was nothing to
   adopt. `common::defer::defer_action` remains unused (`#[allow(dead_code)]` in F2's file, which is
   outside this package).
3. **`content_icon` did not exist as a prefix-chain helper.** F1 added
   `factory::content_icon(icon_region, type_name, size)` (different signature, single region), so
   step 3's "else" branch was used: one `content_texture`+`icon_rect` copy in
   `campaign/util.rs`.
4. **The plan's "only `row_rows` is byte-identical" is not exact.** Mechanical diff shows
   `row_bool`, `row_bool_or`, `row_arr`, `row_dict` and `row_rows` are byte-identical;
   `row_i64`/`row_i64_or` only look identical because their callees differ
   (`int_of` vs `variant_i64`). The equal readers were merged and the four differing ones kept, as
   the same step's rule requires.
5. **Beyond the named list.** `ui_bool`, `dialog_node`, `ui_root`, `set_toggle`, `panel_with_box`
   and `json_stringify` (the `planet/chooser.rs` copy) are also byte-identical, so they follow the
   same re-export route; `setting_get_int` has no planet caller and its re-export carries
   `#[allow(unused_imports)]` to keep the ported surface. `preview_node` is identical but unused in
   the planet page, so it stays planet-local with `#[allow(dead_code)]`.
6. **No rename of the differing row readers.** `row_str`/`row_opt_str`/`row_i64`/`row_i64_or` keep
   their names in both modules (each is only glob-imported by its own subtree); doc comments now
   state the stringified-vs-`GString` difference (RULES §4 allows keeping the local copy).
7. **Line numbers.** All plan line ranges are at `291e30a8`; at `4e33a65a` the items were located by
   name. The item set was complete (no helper missing or extra), except `strip_color_tags`
   (deviation 1 above, already gone before S04).
8. **Close buttons.** Only the five `210.0` sites in owned files changed; `campaign_rules.rs`
   (`200.0`, H05b) and `sector_select.rs` (`0.0`, a custom width) keep their explicit calls.
