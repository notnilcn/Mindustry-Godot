1. **`building_center` was not promoted.** See §2 — the bodies differ (H08's report was written
   before X02 moved the arms); RULES §4 says keep them. Recorded in `sim/AGENTS.md`.
2. **`capture_played_sector` was deleted with its test.** X01 said "drop it unless the findings fix
   wants it"; 02-FINDINGS #2's fix landed through `on_captured_sector` (the shared bookkeeping) and
   nothing calls the forced-capture wrapper.
3. **`game::runtime`'s flat re-export block stays.** S02 suggested C01 could drop it after
   rewriting consumers; 211 call sites across three crates use `game::runtime::{…}`, and the block
   is the module's documented public surface, so dropping it would be a mechanical sweep with no
   cleanup value. The block is now described in `game/AGENTS.md`.
4. **Multi-item `file:line` ranges collapse to their start.** A moves table cannot express a
   range that spans several moved items (e.g. `sim_host.rs:7199-7245` covers `process_capture` and
   `player_core_items`). 31 such refs keep an accurate start pointer instead of a stale range.
5. **One accidental write to `$MAIN`.** An early version of the ledger script wrote the five
   ledger files in the main checkout instead of the worktree. They were restored exactly
   (`git -C $MAIN checkout --`; `git status` clean) before anything else, and the whole ledger pass
   was re-run from the restored files inside `$WT`. No `$MAIN` file differs from its commit.
6. `mp_scenarios::percentile` keeps its local copy (different rank formula) — a documented
   exception to the H09a "four copies" note.
