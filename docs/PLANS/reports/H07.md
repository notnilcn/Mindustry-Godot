## Deviations from the plan

- **Optional `LogicFixture` builder (step 5) skipped.** It is explicitly conditional (“add it only
  if it makes the tests shorter … convert at most one file”). The shared `campaign_sim()`,
  `finish_sim(..)` + `install_campaign_session`/`install_logic_world` and
  `place_world_processor` already remove the copy-pasted construction the builder targeted, and
  the 82 `tick_n` call sites cover the tick loops. A builder would restructure 59 test bodies and
  11 rule tweaks, where a wrong default silently changes a world — not worth it for a test-only
  dedupe whose guard is only the checksum/golden run. Recorded as a follow-up if a later wave
  wants a declarative processor fixture.
- **`spawn` helper added but unused.** The plan lists it, but no local `spawn` wrapper existed at
  HEAD (the observed `spawn(&mut harness, …)` calls are unrelated local closures), so there was no
  body to copy or call sites to adopt. It carries `spawn_live_unit(.., 0.0)` as the plan comments
  and stays for later adoption; the module's `#![allow(dead_code)]` keeps clippy quiet.
- **`builder::tests::with_campaign` kept local.** It looks like `install_campaign_session` but
  takes the campaign registry from `sim.unit_runtime().content` and sets the session `Playing`;
  `install_campaign_session` reads `BuildHarness::load_content()`, so per RULES §4 the bodies
  differ and the local copy stays.
- **Fixture-name variants.** `spine_tests::ability_queue_tests::live_sim` (seed 7, 24×24) is gone;
  call sites use `live_sim_seeded(7, 24)`, whose name states the difference from combat's
  `live_sim` (seed 1, n×n). `unit_runtime::tests::install` became `install_live_runtimes`.
  `builder::tests::sim_with_player` keeps its name but starts from `live_sim_seeded(7, 64)`.
- **Line references** in `test_support.rs` doc comments are the plan's BASE/HEAD-ish numbers for the
  fixtures they cite; the fixture bodies themselves are at those functions, not the line numbers.
