## Deviations from the plan

1. **`net/join/version_gate.rs` holds only the version gate.** The table's `2589–3239 →
   version_gate.rs` range also spans the tail of the join UI (`join_probe_first_match`,
   `join_public_match`, `join_match_version`, `join_install_poll`, `join_shown`,
   `join_on_search_changed`, `join_connect_confirm`, `join_hook_picker`, … `join_close`). Those
   functions build/refresh the dialog and are not part of the gate, so they stayed in
   `net/join/mod.rs`; the plan's own "Item" column names only `JoinVersion`/`JoinSafeConnect`.
   `join_version_string`/`join_abort_on_version` (rendering/abort of the gate) went to
   `version_gate.rs` and are `pub(super)`.
2. **The `dispatch` preamble is not moved to a util leaf.** The arms were distributed to the ten
   destination leaves and the three batch files keep the `dispatch(_id) -> None` stub, per
   W1-DIALOGS-COMMON step 3, so `net/util_b`/`util_misc` contain only helper items.
3. **`pane_colors_are_stable` → `campaign/campaign_complete.rs`.** The plan left it as "the file of
   its owner"; in `misc.rs` it sits between the playtime test and the roster tests, and the only
   `misc` controller that touches a pane-like surface is the campaign-complete banner. Its relative
   import `super::super::super::kit::styles` was rewritten to the equivalent `crate::ui::kit::styles`
   (RULES §3.3) because it now sits one module deeper.
4. **`string_array` moved to `net/util_misc.rs`** (it is inside the preamble range), and its test to
   `pickers/list_select.rs` as the plan says; `ListSelectDialog` imports it from the new location.
5. **`STAT_ROWS`, `padded`, `set_button_text`, `stringify_object`, `parse_json_array` went to
   `game/util_b.rs`** even though their only user is `paused`/`game_over`/`join`: W1-DIALOGS-COMMON
   says to move a batch file's shared-helper section *whole* into the util leaf. No dedupe.
6. **`mind_core::io::FileSystem` stayed on the `game/load.rs` import list** although no line names it:
   `NativeFs.read(…)` needs the trait in scope (the compiler caught it).
7. **Rustfmt signature reflow** of the eight long helper signatures listed above (11 line
   instances) is the only text-level difference in moved code besides the visibility prefixes and
   the one relative-import rewrite in a test.
